# Backup & restore

**Settings → Backup & restore**

- **Create backup** — one ZIP with the logbook, your edits, the settings and every flight file,
  byte for byte. Downloaded terrain is left out; it downloads again when needed. Save it to
  Drive, a PC, or send it to yourself.
- **Restore** — open a Thermik backup ZIP:
  - **Merge** adds the flights you do not have yet and keeps everything else.
  - **Replace** wipes the logbook first and also restores the settings.

For a new phone: create a backup on the old one, install Thermik on the new one, restore with
**Replace**. A folder you imported before needs to be picked once more on the new phone if
you want **Sync** to keep watching it.

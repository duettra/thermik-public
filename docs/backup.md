# Backup & restore

**Settings → Backup & restore**

- **Create backup**: one ZIP with the logbook, your edits, the settings and every track file,
  byte for byte. Downloaded terrain is left out; it downloads again when needed. Save it to
  Drive, a PC, or send it to yourself.
- **Restore from file**: open a Thermik backup ZIP, then choose:
  - **Merge into this logbook** adds the activities you do not have yet, fills in edits you
    have not made here, and keeps everything else.
  - **Replace this logbook** wipes the logbook first and also restores the settings. Thermik
    asks once more, with the numbers on both sides.

Android's own phone backup does not include Thermik, so keep this ZIP somewhere safe.

For a new phone: create a backup on the old one, install Thermik on the new one, restore with
**Replace this logbook**. A folder you imported before needs to be picked once more on the new
phone if you want **Sync** to keep watching it.
